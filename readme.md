# 👑 ViGarik Squad Bot
Профессиональный Telegram-бот для управления и автоматизации сети кланов **ViGarik Squad** в Brawl Stars. Бот полностью интегрирован с официальным Brawl Stars API от Supercell, что исключает ручной ввод данных, автоматизирует контроль кубков, иерархию ролей и ведение сезонных пуш-целей.

## 🚀 Основной функционал

### 1. Автоматическая верификация и аппрув игроков
*   **Регистрация по тегу:** Новые игроки регистрируются в ЛС строго по уникальному тегу (`Player Tag`), бот автоматически забирает их ник, кубки и тег клуба из Brawl Stars.
*   **Двойная верификация (Защита списков):** После ввода тега бот отправляет всей модерации в ЛС интерактивную карточку запроса на авторизацию.
*   **Умное скрытие уведомлений:** Как только первый свободный администратор одобряет или отклоняет заявку, у остальных модераторов сообщение бесшумно удаляется, а у Президента преобразуется в итоговый отчет.

### 2. Динамические ростеры кланов (Списки)
*   **Ежечасный авто-апдейт:** Бот раз в час в фоновом режиме опрашивает API по каждому участнику базы, обновляя кубки и ники в SQLite.
*   **Ежеминутный таймер:** Под каждым закрепленным сообщением в Telegram тикает живой таймер обратного отсчета: `⏳ Трофеи обновятся через: ММ:СС`.
*   **Иерархия и топ-сортировка:** Внутри каждого блока должностей (Лидер, Гранд Вице, Вице, Участники) игроки автоматически выстраиваются строго по кубкам от большего к меньшему. Global ТОП-3 клана получают честные медали (`🥇🥈🥉`).
*   **Бесшумный рефреш:** Бот мягко редактирует старые сообщения, не создавая спам-закрепов в топиках.

### 3. Автономное управление твинками (Админка)
*   **Добавление в 1 клик:** Для добавления твинка админу достаточно отправить Telegram ID/юзернейм основы игрока и игровой тег твинка.
*   **Авто-поиск клана:** Бот сам считывает из игры текущий клуб твинка, сопоставляет его со словарем `CLAN_TAGS` и заносит в нужный список. Ручной выбор кланов админом полностью вырезан.

### 4. Сезонные цели пуша (Строго для Основы)
*   **Умный личный таймер:** Обычный игрок основы при нажатии кнопки пуша видит живой таймер до дедлайна фиксации выбора (2 дня) и точные, рассчитанные от ТОП-1 игрока клана (**X**) нормы кубков без лишних технических формул на экране.
*   **Контроль для Президента:** Лидер в реальном времени видит список пушеров, где у каждого игрока пишется остаток времени до фиксации или замок (`🔒`), если 2 дня истекли.
*   **Автоматический контроль штрафников:** Команда `/check_season` запрашивает API и сверяет результаты финиша игроков с их лигой по правилам:
    *   *Пуш трофеев:* Кубки >= **X / 1.2** + Лега 1 **ИЛИ** Кубки >= **X / 1.1** + Мифик 1.
    *   *Пуш лиги:* Лега 3 + Кубки >= **X / 1.3** **ИЛИ** Мастер + Кубки >= **X / 1.35**.

### 5. Компактный интерфейс админки
*   **Система папок:** Все административные кнопки пуша и предложек спрятаны в интерактивную вкладку `🎯 Управление пуш-сезоном`, разгружая экран.
*   **Жесткая защита от обычных игроков:** Проверка админ-доступа переписана на строгую валидацию текста роли (`role != "member"`), полностью исключая баги с показом админ-кнопок рядовым участникам.

## 📂 Архитектура папки `push_system`
Вся сезонная пуш-логика изолирована в отдельный независимый модуль, чтобы не перегружать код проекта:
*   `__init__.py` — Инициализация модуля и экспорт единого `push_system_router` для `main.py`.
*   `handlers.py` — Обработка реплай/инлайн кнопок пуша, расчет личных таймеров игроков, вывод статистики Лидеру и админ-команды.
*   `services.py` — Массовая рассылка старта сезона, сбор «должников» и публикация списков с жесткими тегами (`@username`) в новости основы.
*   `control.py` — Скрипт автоматического расчета штрафников в конце сезона по формуле `ТОП-1 / Коэффициент`.

## 👔 Команды Разработчика / Владельца
Данный блок команд зашит на верхнем уровне диспетчера и доступен строго владельцу системы по его Telegram ID (`7899153362`):
*   `/SetupBotVigarikThreads` — Автоматическое развертывание структуры топиков логов («Общие логи админки», «Логи Основы», «Логи Академии», «Логи Ивентов») в вашей супергруппе логов с привязкой их ID к БД на лету.
*   `/reload_config` — Принудительная перезагрузка файла настроек и ролей `config.py` без перезапуска процесса бота.
*   Команда, содержащая текст `get_id` — Выводит ID текущей группы и текущего топика для удобного внесения правок в конфигурацию.
*   `/start_season` — Фиксация начала пуш-сезона (техническая заглушка).
*   `/check_season` — Принудительный запуск проверки выполнения сезонных норм по API с выводом списка штрафников.

## ⚙️ Установка и фоновый запуск (Linux VPS)
1. Находясь в папке `/root/vigarik_bot`, активируйте окружение и обновите зависимости:
   ```bash
   source venv/bin/activate
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
2. Для круглосуточной работы 24/7 запустите бота внутри сессии утилиты `screen`:
   ```bash
   screen -S vigarik_prod
   source venv/bin/activate
   python main.py
   ```
   *Чтобы свернуть окно, нажмите:* `Ctrl + A`, затем сразу `D`.  
   *Чтобы вернуться к просмотру логов:* `screen -r vigarik_prod`.
