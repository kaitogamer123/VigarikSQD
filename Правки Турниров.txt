--------------------------------------------------------------------------------
БАГ 1 (P0). _bracket_layout: лишний раунд при n = степени двойки
--------------------------------------------------------------------------------
Файл: handlers/admin_features/bracket.py, функция `_bracket_layout` (строки 72-113).

Симптом (проверено симуляцией):
    n=4  -> раунды [2, 2]        должно быть [2, 1]
    n=8  -> [4, 4, 2]            должно быть [4, 2, 1]
    n=16 -> [8, 8, 4, 2]         должно быть [8, 4, 2, 1]

Причина: `playin = n - size // 2`. Когда n == size (4, 8, 16…), получается
playin = size/2 > 0, и код уходит в ветку плей-ина, хотя автопроходов нет.
В итоге первый круг дублируется «нулевым» вторым кругом.

Что сделать: явно разделить два случая (см. готовый код в разделе 6):
  - autos == 0  -> один полный первый круг, дальше обычное деление на 2;
  - autos > 0   -> плей-ин + второй круг со слотами под автопроходы.

--------------------------------------------------------------------------------
БАГ 2 (P0). _bracket_layout: неверное число слотов второго круга
--------------------------------------------------------------------------------
Файл: handlers/admin_features/bracket.py, строки 99-104.

Симптом:
    n=7  -> [3, 3, 1]    (7 матчей вместо 6)
    n=13 -> [5, 5, 2, 1] (13 вместо 12)
    n=15 -> [7, 7, 3, 1] (15 вместо 14)
    n=25 -> 25 матчей вместо 24
    n=26 -> 26 вместо 25, n=29 -> 29 вместо 28, n=31 -> 31 вместо 30
    (то есть все n, где autos < playin, а не только 7/13/15)

Причина: слоты второго круга собираются как
    for j in range(playin): [None, autos[j]]
    slots.extend(autos[playin:])
то есть длина = 2*playin + (autos - playin) при autos > playin, и 2*playin при
autos <= playin. А должно быть ровно size/2 слотов (= playin + autos) всегда.
Когда autos < playin (7/13/15 команд), слотов больше, чем нужно, и появляются
лишние матчи, из-за которых сетка не сходится к одному финалу.

Что сделать: слоты второго круга = `[None] * playin + list(names[:autos])`.
Это гарантирует playin + autos = size/2 слотов, ровно size/4 матчей.

БАГ 3 (P0). _advance_winner: победитель не проходит дальше при 1 матче в раунде
--------------------------------------------------------------------------------
Файл: handlers/admin_features/bracket.py, `_advance_winner` (строки 170-201),
признак «есть следующий раунд» — строки 181-185:
    total = SELECT COUNT(*) ... WHERE round_no = <текущий>
    if total > 1: ...

Симптом (проверено симуляцией на временной БД): турниры на 3, 5, 9, 13, 15, 17
команд никогда не завершаются. Победитель первого матча записывается, но в
следующий круг не попадает — финал не играется, статус «running» навсегда.

Причина: количество матчей в текущем раунде не говорит о том, есть ли
следующий раунд. У турнира на 3 команды в первом круге ровно 1 матч (total=1),
но финал существует. У турнира на 5 команд первый круг — тоже 1 матч.

Что сделать: считать число раундов от числа команд:
    size = next_pow2(team_count); total_rounds = log2(size)
и продвигать, если `round_no < total_rounds`. Дополнительно не продвигать
матчи ветки `bracket='third'` (матч за 3-е место — тупиковый).

Внимание: нельзя просто заменить `total > 1` на `total >= 1` — тогда финал
начнёт создавать 13-й раунд. Нужно именно сравнение с total_rounds.

БАГ 4 (P0). Отрисовка сетки падает с IndexError
--------------------------------------------------------------------------------
Файл: handlers/admin_features/bracket_image.py, `render_bracket_image`:
  - расчёт Y-координат: строки 135-147 (`prev[2*j]`, `prev[2*j+1]`);
  - соединители: строки 319-325 (`ys_per_round[r+1][j // 2]`);
  - grid_bottom: строка 147.

Симптом (проверено расчётом): для всех n >= 3 предпросмотр сетки
(matches=None, используется при публикации анонса) падает с IndexError,
потому что второй раунд содержит больше пар, чем половина первого.
Например n=6: R1 = 2 пары, R2 = 2 пары, а код для j=1 читает prev[2], prev[3].

Последствия (Pillow установлен по requirements.txt):
  * tournament_cards.py:105 `_publish_tournament_posts` — исключение
    пробрасывается в `tournament_confirm`: турнир уже создан в БД, но анонс
    не опубликован, отчёт админу не отправлен, рассылка не выполнена.
    Снаружи это выглядит как «турнир создался, но его нигде нет».
  * tournament_start.py:109 — старт уже перевёл статус в 'running' и создал
    матчи, но финальная карточка не опубликована и уведомления не разосланы.
  * tournament_notify.py:50 `_repost_bracket` — падает после подтверждения
    результата, до `_notify_next_pairs` и до финализации турнира.
  * tournament_cards.py:240 `_refresh_tournament_posts` — падает после
    регистрации команды (сама команда при этом уже записана).

Причина: геометрия предполагает идеальное двоичное дерево (каждый раунд ровно
вдвое меньше предыдущего). Схема «плей-ин без фейковых BYE-матчей» этому не
удовлетворяет: во втором круге часть слотов занята автопроходами, поэтому
матчей там может быть больше, чем половина матчей первого круга.

Что сделать (минимум два действия):
  1) Считать Y по закрытой формуле, не обращаясь к предыдущему раунду:
         p = match_h + pair_gap
         center(r, j) = y_top + ((j - 0.5) * 2**r - 0.5) * p + match_h / 2
     где r — номер раунда с 0, j — номер матча с 1. Для r=0 формула даёт
     ровно текущие координаты.
     Высоту сетки брать как максимум (ys + match_h) по всем раундам, а не по
     первому.
     Соединители рисовать только если `j // 2 < len(ys_per_round[r+1])`.
  2) Обернуть всё тело `render_bracket_image` в try/except Exception:
     логировать и возвращать None. Тогда при любой ошибке отрисовки бот
     использует текстовую сетку (`_bracket_text` / `_bracket_board`) и НЕ
     ломает создание/старт/результаты турнира.
     Вызовы рендера в tournament_cards.py, tournament_start.py,
     tournament_notify.py тоже стоит обернуть в try/except — картинка не
     должна быть критичной для бизнес-логики.

Файл: handlers/admin_features/tournament_start.py, строки 144-223.

Симптом: при 5/6/9/10/11/12… командах во втором круге уже на старте есть

«BYE-сообщение» оставлять только тем автопроходам, у которых соперник ещё не

либо не уведомляй их вручную, либо выставь им notified=1 заранее.

--- handlers/admin_features/bracket.py ---------------------------------------

def _next_pow2(n: int) -> int:
    size = 1
    while size < n:
        size *= 2
    return size


def _total_rounds(n: int) -> int:
    """Сколько раундов в сетке на n участников (минимум 1)."""
    return _next_pow2(max(int(n), 2)).bit_length() - 1


def _bracket_layout(names: list[str]):
    """Раскладка сетки без фейковых матчей с BYE.

    Возвращает (rounds, autos):
      rounds[0] — первый круг: реальные пары (плей-ин) или полный круг;
      rounds[1] — второй круг: пары из победителей плей-ина и автопроходов;
      дальше — пустые пары (None, None) до финала.
    """
    n = len(names)
    if n < 2:
        return [], n

    size = _next_pow2(n)
    total_rounds = size.bit_length() - 1
    playin = n - size // 2      # матчей в первом круге
    autos = size - n            # команд проходят сразу во второй круг

    if autos == 0:
        # Ровно степень двойки: обычный полный первый круг.
        rounds = [[(names[2 * j], names[2 * j + 1]) for j in range(size // 2)]]
    else:
        # Плей-ин: пары из нижней части списка, верхние (autos) — сразу дальше.
        rounds = [[(names[autos + 2 * j], names[autos + 2 * j + 1])
                   for j in range(playin)]]
        # Второй круг: ровно size/2 слотов = playin победителей + autos.
        slots = [None] * playin + list(names[:autos])
        rounds.append([(slots[2 * i], slots[2 * i + 1])
                       for i in range(size // 4)])

    while len(rounds) < total_rounds:
        rounds.append([(None, None)] * (size >> (len(rounds) + 1)))
    return rounds[:total_rounds], autos


def generate_first_round(tournament_id: int, teams) -> None:
    """Создаёт матчи: плей-ин (слоты 1..m1) + предсоздаёт второй круг.

    ВАЖНО: слоты плей-ина нумеруются ПОДРЯД (1, 2, 3...), а не нечётными
    числами. Правило продвижения (slot -> (slot+1)//2, чётность -> сторона A/B)
    тогда само раскладывает победителей по слотам второго круга.
    """
    names = [str(t["name"] or "Команда") for t in teams]
    by_name = {str(t["name"] or "Команда"): t for t in teams}
    layout, auto_n = _bracket_layout(names)
    if not layout:
        return

    for slot, (a, b) in enumerate(layout[0], 1):
        create_match(tournament_id, 1, slot,
                     by_name[a]["id"], by_name[b]["id"])

    # Второй круг предсоздаём только когда есть плей-ин: у степеней двойки
    # он создастся сам в _advance_winner.
    if auto_n and len(layout) > 1:
        for slot, (a, b) in enumerate(layout[1], 1):
            create_match(tournament_id, 2, slot,
                         by_name[a]["id"] if a else None,
                         by_name[b]["id"] if b else None,
                         partial=True)


def _advance_winner(tournament_id, match, winner_id, loser_id, silent=False) -> bool:
    """Записывает победителя в матч следующего раунда. True — если что-то изменилось."""
    init_tournament_tables()
    conn = db.get_connection()
    if match["status"] != "bye":
        conn.execute(
            "UPDATE tournament_matches SET status='done', winner_team_id=?, loser_team_id=?, "
            "finished_at=CURRENT_TIMESTAMP WHERE id=?",
            (winner_id, loser_id, int(match["id"])),
        )

    changed = False
    is_main = str(match["bracket"] or "main") == "main"
    round_no = int(match["round_no"])

    teams_cnt = conn.execute(
        "SELECT COUNT(*) c FROM tournament_teams WHERE tournament_id=?",
        (tournament_id,)).fetchone()["c"]
    total_rounds = _total_rounds(int(teams_cnt))

    # Есть ли следующий раунд — определяем по числу команд, а НЕ по числу
    # матчей в текущем раунде.
    if is_main and round_no < total_rounds:
        nr, ns = _next_slot(round_no, int(match["slot_no"]))
        nxt = conn.execute(
            "SELECT * FROM tournament_matches WHERE tournament_id=? AND bracket='main' "
            "AND round_no=? AND slot_no=?", (tournament_id, nr, ns)).fetchone()
        side = "team_a_id" if int(match["slot_no"]) % 2 == 1 else "team_b_id"
        if nxt is None:
            conn.execute(
                f"INSERT INTO tournament_matches (tournament_id, round_no, slot_no, bracket, {side}) "
                f"VALUES (?, ?, ?, 'main', ?)", (tournament_id, nr, ns, winner_id))
            changed = True
        elif not nxt[side]:
            conn.execute(f"UPDATE tournament_matches SET {side}=? WHERE id=?",
                         (winner_id, int(nxt["id"])))
            changed = True

    conn.commit()
    conn.close()
    return changed
