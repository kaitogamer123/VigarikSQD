# 📁 Система Резервного Копирования (Backup System)

## Описание

Система автоматически создает резервные копии файлов **перед редактированием**. Все бэкапы:
- ✅ Сохраняются в папке `backups/`
- ✅ **НЕ попадают в Git** (исключены в `.gitignore`)
- ✅ Содержат временную метку в имени (YYYYMMDD_HHMMSS)
- ✅ Можно легко восстановить если что-то пошло не так

---

## Использование

### 1️⃣ Посмотреть все бэкапы

```bash
python backup_tool.py status
```

Вывод:
```
📁 РЕЗЕРВНЫЕ КОПИИ ФАЙЛОВ:

Файл                                     Размер     Дата                
──────────────────────────────────────────────────────────────────────
chat_check_20260819_235127.py            3.4 KB     2026-08-19 23:51:27 
config_20260819_235127.py                7.3 KB     2026-08-19 23:51:27 
──────────────────────────────────────────────────────────────────────
Всего бэкапов: 2
```

### 2️⃣ Создать бэкап файла

```bash
python backup_tool.py backup utils/chat_check.py
python backup_tool.py backup config.py
python backup_tool.py backup handlers/start.py
```

Вывод:
```
💾 Бэкап создан: backups/chat_check_20260819_235127.py
✅ Готово! Бэкап: backups/chat_check_20260819_235127.py
```

### 3️⃣ Восстановить файл из бэкапа

```bash
# Восстановить в исходное местоположение (автоматически)
python backup_tool.py restore backups/chat_check_20260819_235127.py

# Восстановить в другое место
python backup_tool.py restore backups/chat_check_20260819_235127.py utils/chat_check_recovered.py
```

### 4️⃣ Удалить старые бэкапы

```bash
# Оставить только последние 5 версий каждого файла, остальные удалить
python backup_tool.py cleanup 5

# Оставить только последние 3 версии
python backup_tool.py cleanup 3
```

Вывод:
```
🗑️  Удален старый бэкап: chat_check_20260819_100000.py
✅ Удалено 1 старых бэкапов
```

## Использование в коде

Если нужно забэкапить файл **перед редактированием** в Python коде:

```python
from backup_manager import create_backup

# Создаем бэкап перед изменением
backup_path = create_backup("utils/chat_check.py")
print(f"Бэкап: {backup_path}")

# Теперь редактируем файл
with open("utils/chat_check.py", "w", encoding="utf-8") as f:
    f.write(new_content)
```

## Примеры сценариев

### Сценарий 1: Я случайно перезаписал важный файл

```bash
# 1. Смотрим какие бэкапы есть
python backup_tool.py status

# 2. Находим нужный бэкап из списка, например: config_20260819_100000.py

# 3. Восстанавливаем файл
python backup_tool.py restore backups/config_20260819_100000.py config.py
```

### Сценарий 2: Много старых бэкапов, нужно очистить

```bash
# Удаляет все старые версии, оставляет только последние 5
python backup_tool.py cleanup 5
```

### Сценарий 3: Перед большим редактированием файла

```bash
# 1. Создаю бэкап перед изменениями
python backup_tool.py backup handlers/start.py

# 2. Редактирую файл (знаю что есть бэкап)
# ... изменения ...

# 3. Если что-то пошло не так, восстанавливаю
python backup_tool.py restore backups/start_20260819_151045.py handlers/start.py
```

---

## ⚠️ Важные моменты

1. **Бэкапы НЕ попадают в GitHub** — они в `.gitignore`, поэтому можно не беспокоиться о утечке данных
2. **Имена файлов содержат временные метки** — легко найти нужную версию
3. **Автоматическая очистка старых бэкапов** — используйте `cleanup` чтобы не засорять диск
4. **Лучше создавать бэкап перед крупными изменениями** — это страховка от потери данных
